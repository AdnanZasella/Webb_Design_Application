# Inbox

Drop screenshots here (Dribbble, Pinterest, anywhere). Any file name works.

Then tell Claude "new batch in the inbox". For each screenshot Claude will:

1. Read the pattern and feeling (layout, type, color, texture, mood).
2. Build an original mock page with made-up content in that style, in `designs/<id>/`.
3. Add a library entry in `data/designs.js` with a preview image and a written brief.

The screenshots themselves stay on this computer and are not committed to GitHub,
because they are other people's work. Only the original pages Claude builds are committed.
